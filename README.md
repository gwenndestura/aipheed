# aiPHeed

Food-availability shock detection for CALABARZON, built for DSWD / LGU use.

The system predicts, for each province–commodity series each quarter, whether
PSA-reported production has fallen more than 10% below that series' own seasonal
baseline. It serves a same-quarter **nowcast** and a one-quarter-ahead
**forecast** through a FastAPI backend.

---

## Quick start

Requires **Python 3.13** (developed on 3.13.2).

```bash
git clone https://github.com/gwenndestura/aiPHeed.git
cd aiPHeed/backend

python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # macOS / Linux

pip install -r requirements.txt
pip install -r requirements-dev.txt   # only if you will run the tests

copy .env.example .env           # Windows  (cp on macOS/Linux)
```

Then edit `.env` and set `SECRET_KEY` to anything other than `changeme`.

> **Do not install from the `requirements.txt` at the repository root.** It is a
> 1,375-package `pip freeze` of a whole machine, saved as UTF-16, and it will
> either fail on the byte-order mark or install a great deal of unrelated
> software. The correct file is `backend/requirements.txt` (157 packages).

### Verify the install

```bash
python -m pytest tests -q
```

102 tests should pass. If they do, everything below will work.

### Run the API

```bash
uvicorn app.main:app --reload
```

Interactive docs at <http://127.0.0.1:8000/docs>.

## What works straight after cloning

The repository ships the trained models and every data file the API reads, so
the service runs without fetching anything:

| | |
|---|---|
| `models/food_availability_model.joblib` | served nowcast ensemble |
| `models/food_availability_forecast_model.joblib` | served one-quarter-ahead variant |
| `data/processed/*.parquet` | the production panel, fused feature matrix, news dataset and every input series |

Currently served range: **2021-Q3 – 2026-Q2**, one quarter behind the calendar,
set by PSA's publication schedule.

## What does NOT work straight after cloning

**The database is created empty and nothing populates it.** Run the migrations
first:

```bash
alembic upgrade head
```

That creates 11 tables. Three of them are used by the auth, review and feedback
endpoints. The rest — `forecast_records`, `shap_records`, `driver_records`,
`alert_records`, `municipal_forecast_records` — have **never held a row**. Their
repository classes in `app/db/repository/` are written but have no callers, and
`Predictor.detect_alerts()` is implemented but never invoked. Every endpoint
currently reads the parquet files directly at request time.

**No admin account exists**, so all eight `/api/v1/admin` endpoints are
unreachable until you create one:

```bash
python scripts/create_admin.py --email you@example.com --name "Your Name"
python scripts/create_admin.py --list
```

**`app/tasks/` is an empty stub.** There is no scheduler and no background
refresh; every number is regenerated by hand with the commands below.

## Common tasks

All run from `backend/`.

### Refresh every data source

```bash
python scripts/refresh_all_sources.py
```

Re-fetches the live sources, rebuilds the FSSI chain and the feature matrix, and
prints a coverage table flagging anything that did not reach the window edge.

Three series **cannot** be fetched and are curated by hand — DOE pump prices
(the site is behind a WAF), BSP OFW remittances (returns HTTP 403) and the SWS
hunger survey (press-release HTML). Asking for a quarter past their coverage
raises `CuratedCoverageError` rather than silently returning a short series;
pass `strict=False` for degraded output with a warning.

### Retrain

```bash
python scripts/train_final.py            # nowcast, writes the served bundle
python scripts/train_forecast_model.py   # one-quarter-ahead variant
```

Results land in `data/processed/final_results.json` and `forecast_results.json`.

### Check what is imputed

```bash
type data\processed\feature_provenance.json
```

Every forward-filled cell is recorded there. Five columns currently impute 2026:
`FSSI`, `unemployment_rate`, `poverty_incidence`, `ofw_remit_yoy_pct` and
`diesel_php_per_l`. **Do not report those cells as observed.**

## Current model

A four-member soft-voting ensemble — LightGBM, RandomForest, ExtraTrees and
Logistic Regression — fitted **per commodity group** with per-group decision
thresholds and smoothed commodity target encoding. 35 features, 6,118 training
observations, evaluated by expanding-window walk-forward over 12 quarterly folds.

Operating figures (shock class, n = 2,382):

| Accuracy | Precision | Recall | F1 | ROC-AUC |
|---:|---:|---:|---:|---:|
| 0.8165 | 0.7015 | 0.6221 | 0.6594 | 0.8139 |

Always quote these against the baselines in the same file: majority class
**0.7145** and seasonal persistence **0.7834**. Recall is the weak number — the
model misses roughly 38% of real shocks, and accuracy alone hides that.
